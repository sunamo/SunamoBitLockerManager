# SunamoBitLockerManager

## Short description

Knihovna pro správu BitLocker šifrování disků z .NET kódu jako WMI wrapper nad Win32_EncryptableVolume. Obsahuje BitLockerManager, BitLockerHelper a enumy se stavy a nastavením šifrování. Vyčleněno ze sunamo.notmine, obsahuje runner a testy.
